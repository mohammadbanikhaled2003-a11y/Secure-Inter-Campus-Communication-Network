🔍 Threat Modeling & PKI Inspector

[S] TH-02: Spoofing (Rogue CA MITM) CRITICAL
Attacker presents unauthorized server certificate signed by untrusted rogue CA.
✔ Defense: Strict client validation enforcing offline Root CA trust anchor only.
[T] TH-06: Tampering (Bit-Flipping / Ciphertext Alteration) HIGH
Adversary modifies bytes or attempts cryptographic cipher suite downgrade.
✔ Defense: AEAD (AES-256-GCM / Poly1305) with HMAC integrity authentication tag.
[R] TH-10: Repudiation (Denial of Privileged Action) MEDIUM
Staff member executes restricted modification on /staff/ and denies responsibility.
✔ Defense: Non-repudiation audit logging of authenticated client certificate DN ($ssl_client_s_dn).
[I] TH-01: Information Disclosure (WAN Eavesdropping) CRITICAL
Adversary sniffs unencrypted cleartext payload traversing between campuses.
✔ Defense: Site-to-site IKEv2 / IPsec tunnel with AES-256-GCM and Curve25519 PFS.
[D] TH-05: Denial of Service (Cleartext Leak / Fail-Open) CRITICAL
IPsec daemon crashes; default routing exposes packets in cleartext (Fail-Open).
✔ Defense: Fail-Closed firewall drops all non-ESP inter-LAN transit immediately.
[E] TH-03: Elevation of Privilege (Revoked Cert / Replay) HIGH
Terminated staff member uses revoked certificate or replayed ticket on /staff/.
✔ Defense: Real-time CRL verification (returns HTTP 403) and 300s Replay Cache window.

• Algorithm: ECDSA P-384 / SHA-384 (5-Year Validity)
• Deployment: Air-gapped, isolated from network and containers
• Constraint: pathlen:1 (Signs Issuing CA only)
🏢 Online Issuing CA: AABU SCP Issuing CA g06
• Algorithm: ECDSA P-384 / SHA-384 (2-Year Validity)
• Deployment: Online authority for leaf certificates & CRL
• Constraint: pathlen:0 (Signs end-entities only)
• CRL Distribution: http://pki.g06.scp.lab/crl/issuing.crl
